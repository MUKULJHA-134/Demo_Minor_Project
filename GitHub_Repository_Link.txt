Instructions to Deploy on GitHub Pages:
1. Push all source_code files to a GitHub repository
2. Go to Settings → Pages → Source → Deploy from branch
3. Select branch: main, folder: /source_code
4. Your site will be live at: https://your-username.github.io/taskflow-task-management/

Instructions to Deploy on Vercel:
1. Go to https://vercel.com and sign in
2. Click "New Project" → Import from GitHub
3. Set the root directory to "source_code"
4. Click Deploy — no build configuration needed!
